## [2.1.0] — 2026-09-20

### Added

- Public **Release Trust Center** at `/release-trust`.
- Local browser SHA-256 calculation for APK, EXE, ZIP, and other release artifacts up to 512 MB.
- Keyless CIRCL Hashlookup integration with explicit one-time consent per digest lookup.
- Session-only visualization of CIRCL trust context with a clear “not an antivirus score” qualification.
- Optional, append-only `release_trust_events` database ledger that stores only provider, outcome, consent, upload status, digest algorithm, and timestamp.
- Foreground verification timeline showing local input, digest validation, network consent, provider response, and optional persistence state.
- Deterministic GitHub release archives with SHA-256 checksums.
- GitHub/Sigstore artifact attestations generated by `actions/attest@v4` on tagged releases.
- Strict `gh attestation verify` command that checks repository, signer workflow, source tag, and GitHub-hosted runner policy.
- Node.js `25.9.0` pins for local development, Docker, CI, and release builds.
- Render health endpoint at `GET /healthz`.
- GitHub Actions CI for type-checking, tests, and production builds.
- Public documentation for the live Render service, privacy boundary, signed provenance, and self-hosting.

### Changed

- The main workspace now advertises the Release Trust Center from its primary navigation and evidence chips.
- Public defensive analysis now fails soft when optional database persistence is unavailable.
- The production Express server binds explicitly to `0.0.0.0` and suppresses the `X-Powered-By` header.
- Sentinel Atlas application version advanced from `2.0.0` to `2.1.0`.

### Security

- No file-upload route exists for reputation lookup.
- Raw digests, filenames, file paths, file bytes, and provider trust scores are excluded from optional persistence.
- Reputation lookups accept only canonical 64-character SHA-256 input and are rate-limited per client.
- CIRCL absence is labeled **not found**, never **safe**.
- Provider outages and database outages do not block local hashing or the core workspace.
- Release archives are built and attested on GitHub-hosted runners from protected tag references.
- Patched AWS SDK, tRPC, Axios, Drizzle ORM, MySQL2, Nano ID, lodash, and Express routing dependency lines remove all known high and critical production advisories at release time.
- ClamAV found zero infected files in the final source and production build; source/config secret scanning found zero credentials after excluding dependency integrity metadata.
